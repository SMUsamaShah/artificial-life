How replication is detected

Each particle carries a 64-byte program. Nearby particles join and run their tapes, then keep the rewritten halves. After a large copying event the detector runs independent five-generation trials with fresh random partners. Gold marks tapes matching the verified byte pattern.

Movement, starting tapes, and mutation changes restart the same seed. In Heritable attraction, the last tape byte sets the strength of each turn toward a trail.
